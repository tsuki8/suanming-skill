## 定位与边界

`scripts/eastern_divination.py` 是可审查、可复现的东方占卜入口，第一种内置方法为梅花易数。它把固定输入
转换为本卦、互卦、变卦和体用关系，再提供象征性反思问题。它不读取系统当前时间、不生成随机数、不证明
吉凶，也不把传统体系包装成科学预测。

一次只处理一个清晰问题，并要求 `--first-cast` 确认没有为追求满意答案而重复起卦。医疗、用药、心理危机、
自伤、犯罪、诉讼、投资、借贷、博彩与失踪人员搜救等高风险问题会被程序拒绝。

## 数字起卦

本项目的数字卦采用明确的三数报数接口。用户须一次提供三个 100–999 的三位整数，不得由程序随机生成、
补足、拆分或改写：

1. 第一数以 8 取余，结果为上卦。
2. 第二数以 8 取余，结果为下卦。
3. 第三数以 6 取余，结果为动爻。
4. 整除时余数分别按 8、8 或 6 处理。

八卦次序固定为：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。

回归核对例：三个三位数为 202、203、301；取余结果依次为 2、3、1，得到泽火革，初爻变后为泽山咸，
互卦为天风姤。

## 年月日时起卦

必须由用户显式传入当地民用时间，程序不会把运行时刻暗中当作起卦时刻。计算规则为：

- 年支数 + 农历月 + 农历日，以 8 取余为上卦；
- 上式再加时辰数，以 8 取余为下卦；
- 同一总数以 6 取余为动爻。

年支和时辰均按子一、丑二、寅三……亥十二。公历到农历的转换复用锁定的 `iztro@2.6.0`；目前支持
1900–2100 年。闰月沿用同名月份数字，不额外加一；23:00–23:59 的晚子时按输入的民用日期不换日，
两种约定都会在输出中明示。

## 本卦、互卦与变卦

- 六爻数组始终从下往上保存和编号。
- 动爻阴阳翻转后得到变卦。
- 互卦取本卦二、三、四爻为下卦，三、四、五爻为上卦。
- 六十四卦编号和名称采用通行《周易》次序。

## 体用与五行

本项目按卷二口径，把动爻所在的三爻卦定为“用”，未动的三爻卦定为“体”。八卦五行为乾兑属金、
离属火、震巽属木、坎属水、艮坤属土，并输出比和、用生体、体生用、用克体或体克用。

这些关系只生成成本、支持、压力和验证方向等反思提示，不被改写成成功率、吉凶分数或事件保证。

## 本项目的解释层

卦名、上下卦、动爻位置、互卦、变卦和体用是脚本计算事实；每卦的简短主题、六个阶段提示和现实行动
建议是本项目自编的解释层。输出会保留这一区别，并包含至少一个反证问题，减少选择性验证和巴纳姆效应。

找失物时，现实搜索、挂失、冻结和报警优先；卦象不能延误处理。其他领域也必须优先看合同、期限、成本、
当事人真实意愿和专业意见。

## 程序接口

数字起卦：

```bash
python3 scripts/eastern_divination.py \
  --method meihua \
  --question "未来一个月这个项目应优先验证什么？" \
  --numbers 202 203 301 \
  --first-cast
```

显式时间起卦：

```bash
python3 scripts/eastern_divination.py \
  --method meihua \
  --question "未来一个月项目推进需要先验证什么？" \
  --datetime 2026-08-28T15:30+08:00 \
  --first-cast \
  --format json
```

默认输出 Markdown；`--format json` 输出含计算中间值的机器可读结构；`--output PATH` 保存到文件。
