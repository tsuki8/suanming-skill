## 确定性引擎

`scripts/ziwei_pan.mjs` 使用锁定版本 `iztro@2.6.0` 排盘。iztro 采用 MIT License，项目地址：

- <https://github.com/SylarLong/iztro>
- <https://docs.iztro.com/posts/astrolabe>

脚本负责参数校验和稳定输出，不让语言模型口算星曜位置。排盘顺序包括命身宫、十二宫、五行局、十四主星、辅杂曜、生年四化、大限，以及可选目标日期运限。

## 输入与时辰

- 公历：`--solar YYYY-MM-DD`
- 农历：`--lunar YYYY-MM-DD`；闰月加 `--leap`
- 钟表时间：`--hour HH:MM`
- 已知时辰：`--shichen 子|丑|寅|卯|辰|巳|午|未|申|酉|戌|亥`
- 子时：早子时用 `--zi early`，晚子时用 `--zi late`

iztro 的时辰索引为：早子 0、丑 1、寅 2、卯 3、辰 4、巳 5、午 6、未 7、申 8、酉 9、戌 10、亥 11、晚子 12。

出生地仅用于展示和时辰边界提醒。脚本不内置城市经纬度；时间距奇数整点边界不超过 15 分钟时，先核对出生地点与真太阳时，再决定最终时辰。

## 默认参数

| 参数 | 默认值 | 含义 |
|---|---|---|
| `algorithm` | `default` | 以《紫微斗数全书》为基础的通行安星法 |
| `astro-type` | `heaven` | 天盘；仅中州派设置会使用地盘/人盘 |
| `year-divide` | `normal` | 农历正月初一换年 |
| `horoscope-divide` | `normal` | 运限按农历月分界 |
| `age-divide` | `normal` | 虚岁按自然年推进 |
| `day-divide` | `forward` | 晚子时归入次日 |
| 闰月调整 | 开启 | 前半月按上月，后半月按本月 |

比较两个软件或两张盘时，必须逐项统一这些参数。需要中州派时显式传 `--algorithm zhongzhou`，并注明天盘、地盘或人盘。

## 流派差异

紫微斗数不同流派可能在以下位置产生不同结果：

- 四化表；
- 星曜庙旺亮度；
- 闰月前后半月处理；
- 正月初一或立春换年；
- 晚子时归日；
- 通行版与中州派安星法；
- 天盘、地盘、人盘。

发现与其他排盘软件不一致时，不要强行解释。先记录对方软件名称和上述参数，再用同一输入分别运行两种算法进行差异对照。

## 输出字段

Markdown 输出用于直接阅读；`--format json` 输出完整、可机器处理的数据：

- `chart`：本命盘、十二宫和本命星曜；
- `decadals`：全部大限；
- `target`：传入 `--target-date` 后的目标日期大限、流年、流月、流日和流时；
- `config`：本次排盘口径；
- `warnings`：时辰边界等风险。

解读必须以脚本字段为准，不得凭记忆移动主星或四化。

## 验证基准

黄金用例采用 iztro 官方文档中的通用示例：公历 2000-08-16，寅时，女，通行版。

- 农历：二〇〇〇年七月十七；
- 命宫：午；身宫：戌；
- 命主：破军；身主：文昌；
- 五行局：木三局；
- 命宫：紫微；
- 夫妻宫：七杀；
- 官禄宫：廉贞、天府；
- 生年四化：太阳禄、武曲权、太阴科、天同忌。

运行 `npm test` 可验证该基准和全部紫微回归用例。

## 13 时辰校时

出生时间未知但用户明确请求校时时，运行：

```bash
node scripts/ziwei_time_compare.mjs --solar 2000-08-16 --sex 女
node scripts/ziwei_time_compare.mjs --lunar 2000-07-17 --sex 女 --target-date 2025-01-01 --format json
```

脚本依次调用 `ziwei_pan.mjs`，生成早子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥、晚子共 13 个索引。每个候选保留命身宫、五行局、核心七宫主星、生年四化、文昌文曲、红鸾天喜、大限及可选目标日期运限。

校时顺序：

1. 先用出生证明、医院记录、家属记忆、时区和真太阳时缩小范围。
2. 再用有明确年份的迁居、升学、就业、婚恋、手术或家庭变化比较候选大限与流年结构。
3. 优先比较相邻候选的结构差异，排除与事实明显冲突者。
4. 最终保留 2–3 个候选；证据不足时不得输出唯一时辰。

外在印象、发旋、面相、手相或人格分类只能作为低权重自述线索。它们不能取代出生记录，也不能单独证明八字时柱。

## Python 自动化入口

优先用 `scripts/ziwei_auto.py` 处理常规工作流：

```bash
# 已知出生时间：生成 Markdown 六主题事实包
python3 scripts/ziwei_auto.py --solar 2000-08-16 --hour 03:30 --sex 女 --target-date 2026-08-28

# 机器可读 JSON
python3 scripts/ziwei_auto.py --lunar 2000-07-17 --shichen 寅 --sex 女 --format json

# 未知出生时间：自动生成 13 候选比较
python3 scripts/ziwei_auto.py --solar 2000-08-16 --sex 女

# 保存结果
python3 scripts/ziwei_auto.py --solar 2000-08-16 --shichen 寅 --sex 女 --output facts.md
```

Python 脚本不计算命宫、星曜、四化或运限，而是调用 `ziwei_pan.mjs` 或 `ziwei_time_compare.mjs` 获取确定性 JSON。已知时辰时，它自动生成：

- 基本盘、命身宫、命身主和五行局；
- 生年禄权科忌落星落宫；
- 文昌、文曲、红鸾、天喜的位置和状态；
- 事业、财运、身体/心理、感情、整体、学业六个主题的必看宫位事实包；
- 全部大限及可选目标日期的大限、流年四化。

测试入口为 `python3 -m unittest scripts/test_ziwei_auto.py`；项目统一运行 `npm test` 会同时执行 Node 与 Python 测试。
