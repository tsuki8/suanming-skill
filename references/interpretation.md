## 基本原则

- 先排盘，后解读；宫位、星曜、四化和运限一律服从脚本输出。
- 先看结构，再看单星。至少同时观察本宫、对宫及两个三合宫。
- 主星定骨架，辅星与煞曜修正表现，四化说明能量流向，运限说明触发时间。
- 不把单颗星、单个化忌或单一年份解释成必然事件。
- 不用紫微结论覆盖八字结论；两套体系分开说明，最后只比较共同主题。

## 解读顺序

1. 基本盘：命宫、身宫、命主、身主、五行局。
2. 命宫三方四正：命宫、迁移、财帛、官禄。
3. 生年四化：禄、权、科、忌落星及落宫。
4. 核心六宫：命、官禄、财帛、夫妻、迁移、福德。
5. 当前大限：大限命宫、四化及与本命宫位叠合。
6. 流年：只描述倾向、触发主题与可验证时间窗口。
7. 历史校准：提出 3–5 个已发生年份，请用户反馈后再收窄判断。

| 命宫 | 性格底色、应对方式、人生主轴 |
| 兄弟 | 手足、同辈协作、近身支持 |

| 迁移 | 外部环境、异地发展、社会表现 |

| 太阳 | 公开、付出、领导 |
| 武曲 | 执行、资源、财务 |
| 天同 | 温和、享受、协调 |
| 廉贞 | 原则、边界、欲望管理 |
| 天府 | 稳定、储备、管理 |
| 太阴 | 细腻、规划、内在安全 |
| 贪狼 | 社交、欲望、多才多艺 |
| 巨门 | 表达、质疑、研究 |

| 破军 | 重组、突破、先破后立 |

空宫不等于没有该主题。借看对宫主星，并把本宫辅杂曜和三方四正一起分析。

## 四化

- 化禄：资源、机会、偏好和获得感。
- 化权：推动、控制、责任和竞争。
- 化科：名誉、学习、表达与缓冲。
- 化忌：执着、阻滞、代价和需要反复处理的课题。

四化先看“哪颗星化、落在哪一宫”，再看该宫与其他宫位的关系。化忌不等于灾祸，化禄也不等于无条件获利。

## 大限与流年

- 本命盘描述长期结构；大限描述十年环境；流年描述当年的触发。
- 先分析大限，再看流年，不倒因为果。
- 流年四化与本命四化重叠时，主题更集中，但仍需现实事件校准。
- 目标日期必须由 `--target-date` 生成，不得口算流年宫位或四化。

## 专题分析

### 感情

以夫妻宫为核心，同时看命宫、福德、官禄和迁移的三方四正；再看本命与运限四化。只能描述关系模式、对象倾向和窗口，不得声称能锁定“唯一正缘”的姓名、长相或必然结婚年份。

### 事业

以官禄宫为核心，同时看命宫、财帛、迁移和身宫。区分能力结构、组织环境、收入方式与阶段性机会。

### 财运

以财帛宫为核心，同时看官禄、田宅、福德和相关四化。涉及投资时必须提醒用户独立核实并理性决策。

### 健康

只讨论传统文化中的压力和生活习惯象征，不诊断疾病、不预测寿命，明确建议以医疗专业意见为准。
