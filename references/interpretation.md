## 基本原则

- 先排盘，后解读；宫位、星曜、四化和运限一律服从脚本输出。
- 先看结构，再看单星。至少同时观察本宫、对宫及两个三合宫。
- 主星定骨架，辅星与煞曜修正表现，四化说明能量流向，运限说明触发时间。
- 不把单颗星、单个化忌或单一年份解释成必然事件。
- 不用紫微结论覆盖八字结论；两套体系分开说明，最后只比较共同主题。

## 解读顺序

1. 基本盘：命宫、身宫、命主、身主、五行局。
2. 命宫三方四正：命宫、迁移、财帛、官禄。
3. 生年四化：禄、权、科、忌落星及落宫。
4. 核心六宫：命、官禄、财帛、夫妻、迁移、福德。
5. 当前大限：大限命宫、四化及与本命宫位叠合。
6. 流年：只描述倾向、触发主题与可验证时间窗口。
7. 历史校准：提出 3–5 个已发生年份，请用户反馈后再收窄判断。

## 十二宫主题

| 宫位 | 主要主题 |
|---|---|
| 命宫 | 性格底色、应对方式、人生主轴 |
| 兄弟 | 手足、同辈协作、近身支持 |
| 夫妻 | 亲密关系模式、伴侣特征、关系课题 |
| 子女 | 子女、创作、培养与产出 |
| 财帛 | 赚钱方式、资源配置、风险偏好 |
| 疾厄 | 身心负荷与生活习惯；不得替代医学诊断 |
| 迁移 | 外部环境、异地发展、社会表现 |
| 仆役/交友 | 朋友、同事、下属与合作网络 |
| 官禄 | 事业结构、职责、成就方式 |
| 田宅 | 居住、家庭资产、稳定基础 |
| 福德 | 精神需求、压力、满足感 |
| 父母 | 父母、师长、制度与文书支持 |

## 十四主星关键词

这些关键词只用于起点，必须结合宫位、三方四正、亮度和四化：

| 主星 | 结构关键词 |
|---|---|
| 紫微 | 统筹、尊严、中心意识 |
| 天机 | 思考、变化、策略 |
| 太阳 | 公开、付出、领导 |
| 武曲 | 执行、资源、财务 |
| 天同 | 温和、享受、协调 |
| 廉贞 | 原则、边界、欲望管理 |
| 天府 | 稳定、储备、管理 |
| 太阴 | 细腻、规划、内在安全 |
| 贪狼 | 社交、欲望、多才多艺 |
| 巨门 | 表达、质疑、研究 |
| 天相 | 协调、规范、形象 |
| 天梁 | 保护、原则、经验 |
| 七杀 | 决断、压力、开创 |
| 破军 | 重组、突破、先破后立 |

空宫不等于没有该主题。借看对宫主星，并把本宫辅杂曜和三方四正一起分析。

## 四化

- 化禄：资源、机会、偏好和获得感。
- 化权：推动、控制、责任和竞争。
- 化科：名誉、学习、表达与缓冲。
- 化忌：执着、阻滞、代价和需要反复处理的课题。

四化先看“哪颗星化、落在哪一宫”，再看该宫与其他宫位的关系。化忌不等于灾祸，化禄也不等于无条件获利。

## 大限与流年

- 本命盘描述长期结构；大限描述十年环境；流年描述当年的触发。
- 先分析大限，再看流年，不倒因为果。
- 流年四化与本命四化重叠时，主题更集中，但仍需现实事件校准。
- 目标日期必须由 `--target-date` 生成，不得口算流年宫位或四化。

## 专题分析

每个主题按“脚本事实 → 传统解释 → 运限触发 → 现实核验 → 可执行建议”输出。先写支持结论的结构，再写冲突或减弱因素；不要只挑符合预设的星曜。

### 事业

必看顺序：

1. 以官禄宫为核心，查看主星、辅煞、亮度、四化及空宫借星。
2. 务必联看财帛宫、命宫、迁移宫和身宫，形成事业主题的三方四正与行动方式。
3. 按问题补看交友宫的合作网络、父母宫的制度与文书、田宅宫的稳定基础、福德宫的持续投入能力。
4. 先描述本命的能力结构与适合环境，再叠当前大限和目标流年；不得把流年机会写成必然升职、录用或创业成功。

输出至少区分：优势能力、适合的职责/环境、容易消耗的情境、当前阶段触发、现实验证问题。职业建议使用条件句，不按星曜直接指定唯一行业。

### 财运

必看顺序：

1. 以财帛宫为核心，查看资源取得、管理方式与风险偏好。
2. 务必联看官禄宫、命宫和迁移宫，区分收入来源、执行方式与外部机会。
3. 补看田宅宫的长期资产/稳定基础、福德宫的消费满足感，以及禄权科忌的落星落宫。
4. 分开说明赚钱能力、现金流稳定性、储蓄/配置倾向和阶段性波动；不得用“财星好”直接推断必然富有。

涉及投资、借贷、保险、税务或大额消费时，只提供反思问题与风险清单，并提醒独立核实或咨询持证专业人士，不给具体买卖指令。

### 健康：身体与心理

以疾厄宫和福德宫为核心，结合命宫、身宫、当前大限与流年压力主题。用户自述、体检结果和专业意见始终优先于命盘象征。

#### 身体健康

- 只把星曜解释为传统文化中的作息、压力、恢复与生活习惯象征。
- 可以建议记录睡眠、饮食、运动、疼痛或疲劳并进行常规检查；不得诊断器官疾病、预测重病、寿命或治疗效果。
- 若用户提供八字五行旺衰，只能在单独标注的八字段落中解释，不用五行推断营养缺乏或疾病。

#### 心理健康

- 只讨论压力来源、情绪恢复方式、边界和支持系统等非诊断性主题。
- 不把孤辰、化忌、煞曜等同于抑郁、焦虑或人格障碍。
- 用户出现持续痛苦、功能受损、自伤或伤人风险时，停止命理推断并鼓励联系当地急救、危机热线或心理/精神科专业人士。

### 感情与爱情运势

必看顺序：

1. 以夫妻宫为核心，同时看福德宫、迁移宫、命宫及其三方四正。
2. 检查红鸾、天喜的落宫与运限触发，再看本命四化、大限四化和流年四化；红鸾、天喜不能单独证明恋爱或婚期。
3. 需要时补看官禄宫的生活安排、交友宫的社交环境、田宅宫的共同生活基础。
4. 合盘或参考对方宫位前，确认对方同意使用其出生资料；双方命盘分别排出后再比较，不用一方命盘代替另一方意愿。

描述关系需求、相处模式、冲突触发点、支持条件与较活跃窗口。不得声称能锁定“唯一正缘”的姓名、长相、身份或必然结婚/分手年份，不根据命理劝用户追踪、控制或测试他人。

### 整体运势

整体解读不是六个单宫结论的拼接。按以下顺序整合：

1. 概括命宫、身宫、命主、身主和五行局的长期主轴。
2. 展开命宫三方四正：命、迁移、财帛、官禄。
3. 追踪生年禄、权、科、忌从哪颗星流入哪些宫位，并写出资源、责任、表达和反复课题。
4. 先看当前大限，再看目标流年四化与本命/大限的叠合。
5. 把事业、财运、身心、感情和学业中重复出现的主题列为“共同信号”，把互相矛盾的信号列为“需要现实核验”。
6. 如用户提供卧室位置、八字、占星或占卜结果，只在独立补充段落比较一致与冲突，不改变紫微脚本事实。

结论包含：当前阶段主轴、机会条件、主要压力、可观察信号、现实行动建议。强调“命好不如限好”属于传统命理中重视阶段环境的说法，不把大限写成命运定局。

### 学业运势

必看顺序：

1. 定位文昌、文曲的落宫、亮度、同宫星曜及是否化科；同时追踪其他化科星的落宫。
2. 查看命宫主星和命宫三方四正，区分信息吸收、表达、执行和环境适应。
3. 补看福德宫的专注与恢复、官禄宫的目标和纪律、迁移宫的考试/异地环境、父母宫的师长与制度支持。
4. 先看当前大限，再叠目标学年或考试日期的流年；目标日期必须由脚本生成。
5. 若提供八字排盘，只在独立段落讨论传统子平框架下的印星、食神和伤官；不要用紫微星曜代替八字十神。

同届学生只共享部分出生年背景（例如某些生年四化），并不会因此拥有相同命盘或表现。只能把同届共性作为低区分度背景，不可据此预测排名、录取或智力。

输出区分：学习方式、表达/应试、持续性、环境支持、阶段窗口和现实学习策略。不得保证分数、录取或奖学金结果。

## 输出检查表

整体解读交付前检查：

- 是否覆盖事业、财运、身体、心理、感情、整体和学业；“身体/心理”为健康模块的两个小节。
- 每个主题是否满足必看宫位，而非单宫单星断语。
- 是否同时说明生年四化、当前大限和用户所问年份的流年四化。
- 是否把脚本事实、用户事实、传统解释与综合推断分开。
- 是否给出至少一个反证、冲突信号或需要用户核验的问题，以降低巴纳姆效应。
- 是否避免确定性事件、医疗诊断、投资指令和关系操控建议。
